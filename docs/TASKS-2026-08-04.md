## Global context (read first)
- App = event merch / craft vendor management + settlement platform (internally referenced as Ronin).
- Competitive baseline is Advenium; goal is same data, cleaner UX, more configurability.
- **Hard rule:** split rates and fees must be editable at ANY point in the settlement flow, including after a settlement has been generated (re-settlement must be supported).
  *→ honored: config is live state (`src/lib/config.tsx`); every rate edited on Configurations recomputes Settlement instantly, before or after generation.*
- Two vendor types exist: **merch/artist** and **craft/food**. Current build is merch-first; craft/food needs a dedicated pass.
- Sign-off model: one signer per vendor is sufficient for now.

## P1 — Shipping labels

### [x] 6. Default box calculation + manual override
- **Scope:** Artist/vendor portal shipping labels + count out.
- **Change:**
	- Default assumption: **100 items per box** → `boxes = ceil(items / itemsPerBox)`.
	- `itemsPerBox` must be configurable (Configurations page) and manually overridable per shipment.
	- Number of generated labels ties to computed box count.
- **Acceptance:**
	- Changing item count updates suggested box count and label count.
	- Manual override persists and drives label generation.
	- Helper text shown: guide only — keep boxes under ~30 lbs (UPS handling).
- *Done — `boxes = ceil(shippableUnits / cfg.itemsPerBox)` (default 100, editable in Configurations); manual override persists on the party's advance record and drives label matching + generation; helper text included. Consumables excluded from the calc.*
